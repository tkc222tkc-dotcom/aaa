# Music Club App（部活向け）

部活で使える機能を30個入れた、ブラウザだけで動く音楽アプリです。

## 主な内容
- ローカル音源の再生（プレイリスト / 再生操作 / シーク / 音量）
- 部活で使える30機能カード
- 各カードの内容を `localStorage` に保存

## 部活向け30機能
1. 出欠管理
2. 遅刻早退メモ
3. 本日の練習目標
4. 週間練習計画
5. 基礎練メニュー
6. 曲別達成度
7. テンポ目標
8. チューニング記録
9. セクション練習メモ
10. パート割り当て
11. 本番セットリスト
12. MC台本メモ
13. 機材チェック
14. 貸出返却管理
15. 予算メモ
16. 購入リスト
17. 大会カウントダウン
18. 本番タイムテーブル
19. 練習タイマー
20. 休憩タイマー
21. 連絡事項
22. ミーティング議事録
23. 当番表
24. 課題ToDo
25. 改善フィードバック
26. 個人目標
27. 体調管理メモ
28. モチベーション一言
29. 緊急連絡先
30. 振り返り日誌

## 使い方
1. `index.html` をブラウザで開く
2. 「曲を追加」から音楽ファイルを選んで再生
3. 部活向け30機能にメモして保存
